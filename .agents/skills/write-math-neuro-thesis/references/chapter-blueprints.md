# Chapter Blueprints

Use these patterns when the user asks for a thesis structure, chapter outline, or a draft for a specific section.

## Full Thesis

1. Introduction
2. Mathematical and neuroscientific background
3. Problem formulation
4. Methods or model development
5. Results
6. Discussion
7. Conclusion and future work

Adapt this default sequence when the thesis is more theoretical, more empirical, or combines both.

## Introduction

Use this order:

1. Broad problem area
2. Specific gap
3. Why the gap matters in mathematics or neuroscience
4. Thesis objective or research question
5. Main contribution summary
6. Chapter roadmap

## Background

Split background into only the concepts the thesis truly depends on:

- mathematical preliminaries
- computational neuroscience concepts
- prior models or methods
- notation and conventions

Avoid turning the background into a disconnected textbook summary.

## Literature Review

Organize by theme, not chronology:

- theoretical approaches
- mechanistic models
- data-driven or computational approaches
- limits of the current literature
- open gap motivating the thesis

For each cluster, state:

1. what the approach explains
2. what assumptions it makes
3. where it falls short for the thesis problem

## Problem Formulation

Use this section to make the thesis legible:

1. define the system or phenomenon
2. define variables, state spaces, operators, or observables
3. state assumptions
4. specify the target question, prediction, control problem, or inference task
5. explain success criteria

## Methods or Model Chapter

Use this sequence:

1. conceptual overview
2. formal definitions
3. derivation or algorithm
4. implementation or simulation setup
5. evaluation protocol

If the work is theorem-heavy, move proof sketches or full proofs into the order:

1. statement
2. intuition
3. proof strategy
4. technical proof
5. implication

## Results

Keep the section result-centered:

1. restate what is being tested or demonstrated
2. present the result
3. interpret the result
4. compare against expectation, baseline, or prior work
5. note limitations or failure cases

Do not mix long methods detail into results unless it is necessary for interpretation.

## Discussion

Cover:

1. what the results mean
2. what they do not show
3. how they relate to prior work
4. methodological limits
5. implications for neuroscience, mathematics, or both

## Conclusion

Keep it short and decisive:

1. restate the question
2. restate the main contribution
3. state the strongest supported takeaway
4. name the next logical extension
